主题设计：东方夜间仪式感

一、核心定位

整个网站不是"工具 UI"，而是"一个安静的东方数字空间"。
主题关键词：夜间、仪式、木质、香火、克制、停顿。

产品核心不是信息，而是情绪与停顿感。


二、色彩系统

背景：
  不是纯色。由深棕黑、暖灰、暗红组成的低亮度空间，偏安静、压暗。
  暗红在最低层暗示木质与香火感，暖灰在中间层提供微弱的散射深度。

主色调：
  暖木暗金。金色点缀 #d4a030 ~ #fdcb6e，克制使用，不作为大面积主色。

文字层级：
  白色文字不超 85% 不透明度，辅助文字低至 12~18%，制造"暗处观看"的沉浸感。
  关键信息使用暖金色。


三、氛围层（全站统一，极克制）

1. 中央琥珀呼吸光晕
   页面中央有极淡的琥珀色径向光晕，超慢速亮暗循环。
   不是"在发光"，而是"在呼吸"——用户潜意识感知，不明显察觉。

2. 页面 vignette
   从页面中心向四边渐暗的径向覆盖层，让视线自然聚拢。
   四周比中心暗约 10~15%。

3. 背景粒子
   像空气中的香灰、尘埃、微光一样缓慢漂浮。
   透明度非常低，用户应该只是隐约感觉空间"活着"。
   不是炫酷特效，是氛围层。
   速度：极慢。数量：克制。方向：随机缓慢漂移，略有上升趋势（像香灰被热气托起）。

4. 大量留白
   页面不能塞满内容。呼吸感来自留白，不是来自填充。


四、按钮设计

主按钮：
  深色半透明底 + 细金边 + 轻微内发光。
  不透明、不抢眼，融入暗色背景中。

hover：
  不是突然变亮。缓慢泛起一层暖金色微光，像灯火被轻轻点亮。
  使用 CSS transition，持续时间 0.6~0.8s。

点击：
  不能立刻触发结果。先有轻微下沉感（scale 0.98 + 阴影收缩），再进入动画。

选中/激活：
  加入极轻微呼吸效果：scale 1.02 + 亮度提升约 5%，伴随便慢的金边呼吸。
  用户不应该明显感觉"它在动"，而是潜意识觉得这个元素有生命。


五、卡片设计

hover：
  轻微上浮（translateY -2~4px）、阴影扩散、边缘变暖。
  像物体被光轻轻照到，不是弹跳。
  使用 CSS transition，持续 0.4~0.6s。

普通状态：
  深色半透明底，微金边或无边，融入背景。


六、动效铁律

所有动画统一"缓慢、有重量、有惯性"的节奏。
不能使用游戏式快速反馈、不能高频 pulsing。

交互流程：触发 → 等待 → 浮现
不是"点击→结果"，而是"动作→停顿→揭示"。

动画的重点不是"元素在动"，而是"光与空气在呼吸"。
真正高级的感觉来自克制，而不是复杂。

禁止：
  鲜艳色彩、强对比
  <0.3s 的快速动画
  花哨 emoji、段子文案
  老虎机/赌博式刺激
  高频 pulsing、弹跳


七、各页面差异化氛围

虽然全站统一基底，但每个页面有独立气质：

首页：
  最中性。琥珀光晕最亮（但仍极克制），粒子最柔和。
  欢迎感，但不能亮——仍然是"深夜的入口"。

求签页：
  最暗。比首页再暗约 10%，光晕更集中、更暖。
  微雾感——可以在 vignette 中混入极淡的暖灰。
  粒子更少、更慢。仪式进行中时粒子几乎停止。
  出签后：背景变安静，光线略亮，微粒停止——"仪式结束了"。

摇骰子页：
  粒子稍活跃，略有动感。
  光晕可以微偏暖金色，呼应"命运感"。

选啥页：
  更柔和、更轻松。
  卡片浮动感更强，光晕偏中性。


八、实施优先级

第一梯队（现在）：
  1. 页面 vignette
  2. 按钮/卡片 hover transition
  3. 中央琥珀呼吸光晕
  4. 点击下沉反馈

第二梯队：
  1. 背景粒子（香灰/尘埃）
  2. 背景渐变色深化（暖灰+暗红层次）
  3. 按钮选中呼吸效果

第三梯队：
  1. 各页面差异化氛围
  2. 出签后页面状态改变
  3. 粒子随页面状态变化
