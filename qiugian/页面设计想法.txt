产品页面问题整理（单独归档版）

---- 讨论后的核心共识 ----

核心价值观: 从"功能动作"到"仪式动作"——慢、克制、有重量
核心竞争力: "随机被赋予仪式"——不是换素材，是做节奏
不追求炫，追求"有生命"

开发顺序:
  第一阶段: 求签页沉浸化(灵魂页，最易出圈)
  第二阶段: 全局氛围层(世界观增强器)
  第三阶段: 选啥/摇骰同步仪式感

素材策略: 第一阶段全用 CSS + 现有 PNG——节奏和动效是高级感的来源，素材是后期加成

签条技术路线: 签筒保留 4.png 作容器，签条独立为 DOM 元素，每根可单独控制(抖动/位移/突出)

求签仪式的理想流程:
  长按 → 签筒不规则抖动(有惯性、回弹、力度变化，非匀速旋转)
       → 签条微微上下错位，有一根逐渐比别的更突出
       → 松手 → 该签慢慢滑出 → 掉落 → 停顿 → 页面安静 → 再出签文

选啥洗牌的理想流程:
  点击 → 按钮消失 → 三张卡片缓慢交错交换(人在理牌，非老虎机)
      → 卡片翻面(？→背面→正面)
      → 一张停住，其余暗下去 → 0.8s 停顿 → 选中卡片慢慢翻开 → 文字浮现

全局氛围层建议结构:
  全站统一: 极淡漂浮粒子、超慢呼吸光晕、背景纹理、微弱 vignette
  各页差异: 求签更暗更静、摇骰更动感、选啥更柔和

统一原则:
  ① 不要立刻反馈——加入停顿、缓慢、等待感
  ② 不要太白话——东方克制感
  ③ 不要太亮——深夜感
  ④ 不要太满——留白
  ⑤ 不要太互联网——减少花哨 emoji、强色彩、段子感

一、首页（当前最大问题：太像列表页）
当前问题
1. 缺少“入口感”

现在像：

功能列表

而不是：

“进入一个空间”
2. 缺少情绪引导

用户打开后：

不知道：
这个网站到底是什么气质。

3. 首页太静

没有：

呼吸感
微动态
情绪流动
解决方案
① 增加一句核心文案（重要）

放在标题下面。

例如：

这里没有标准答案，
只有当下的方向。

或者：

映照当下，
辅助决策。
② 首页背景增加“氛围层”

推荐：

超轻微漂浮粒子

效果：

香灰
尘埃
微光

要求：

极淡
极慢
③ 卡片增加 hover 动效

当前：

太静。

建议：

hover 时：

微微上浮
边缘亮一点
阴影扩散
缓慢呼吸

注意：

一定克制
④ 首页卡片间距拉大一点

现在：

略挤。

建议：

增加：

上下呼吸感
空气感
⑤ Footer 太弱

现在几乎不可见。

建议：

加入一句：

随机未必正确，
但能看见犹豫。

这种情绪句子。
